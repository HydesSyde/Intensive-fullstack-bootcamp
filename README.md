Full-Stack JavaScript Bootcamp
A 4-month, project-based fullstack program that takes you from zero to building and deploying a complete web application.
> **Start here:** read the [Syllabus](SYLLABUS.md).
You need:
A laptop (any modern Windows, macOS or Linux machine)
Basic computer skills
A commitment of 6 hours per week
Internet access for lessons and uploads (offline tips are in each week's notes where possible)
>
> What you will be able to do
By the end of Week 16 you will have:
Built and deployed a full-stack web app with a React frontend, a Node and Express backend, a database and user login
4 to 5 projects on your public GitHub profile
The habit of reading documentation, debugging and asking good questions
A CV, a portfolio link and mock-interview practice
Month	Weeks	Focus	Ends with
1: Foundations, HTML and CSS
2: JavaScript	The JavaScript language, the DOM, async code	A working app that uses a public API
3: Frontend	HTML/CSS in depth, React, routing, deployment	A deployed multi-page React app
4: Backend and capstone. Node, Express, MongoDB, authentication, A deployed full-stack capstone and demo day
How to use this repository
Read the week's `README.md` before class.
Do the exercises in the week's `exercises/` folder.
Complete the `assignment.md` and push your work to your own GitHub repo.
Ask questions by opening an Issue.
Report mistakes in the material the same way. Corrections are welcome.
Repository map
```
SYLLABUS.md        the 16-week plan
RESOURCES.md       curated free learning links by month
month-*/week-*/    weekly notes, exercises and assignments
projects/          capstone brief and grading rubric
assets/            images and diagrams
```
