## 📌 Programme Overview

| 📋 Detail             | Description                                          |
| :-------------------- | :--------------------------------------------------- |
| **Duration**          | 4 Months / 16 Weeks                                  |
| **Target Audience**   | Beginners and aspiring software developers           |
| **Primary Language**  | JavaScript                                           |
| **Frontend**          | HTML, CSS, Tailwind CSS, React                       |
| **Backend**           | Node.js, Express.js                                  |
| **Database**          | MongoDB or PostgreSQL                                |
| **Version Control**   | Git & GitHub                                         |
| **Development Tools** | VS Code, Terminal, Postman, ThunderClient            |
| **Learning Style**    | Live coding, guided labs, pair programming, projects |
| **Assessment**        | Monthly graded projects and code walkthroughs        |
| **Final Outcome**     | A deployed full-stack capstone project and portfolio |

### 🛠️ Choose Your Stack

We'll use JavaScript throughout the programme, with one of the following database paths:

| Stack       | Technologies                              |
| :---------- | :---------------------------------------- |
| 🟢 **MERN** | MongoDB + Express.js + React + Node.js    |
| 🔵 **PERN** | PostgreSQL + Express.js + React + Node.js |

Both stacks teach the fundamentals of full-stack development. The primary database will be selected for the cohort to keep learning focused and practical.

## MONTH 2 — JavaScript Programming

**Weeks 5–8 :**

JavaScript is the foundation of this programme. You'll learn how to solve problems, manipulate data, respond to user actions, and work with information from external services.

### Week 5 — JavaScript Fundamentals

**Topics**

* JavaScript syntax and program structure.
* Variables: `let` and `const`.
* Data types and type conversion.
* Operators and expressions.
* Conditional statements.
* Functions and arrow functions.
* Scope and variable accessibility.
* Debugging with the browser console.

** Hands-On Output**

* Complete daily coding drills.
* Build small calculators and conditional-logic exercises.

### Week 6 — Arrays, Objects & Modern JavaScript

**Topics**

* Arrays and objects.
* Adding, accessing, updating, and removing data.
* Array methods: `map()`, `filter()`, `find()`, and `reduce()`.
* Destructuring.
* Spread and rest syntax.
* Template literals.
* ES modules and imports/exports.
* Processing and transforming data.

** Hands-On Output**

* Complete data-processing exercises.
* Build a small application that filters and organises a collection of records.

### Week 7 — The DOM & Interactive Applications

**Topics**

* The Document Object Model (DOM).
* Selecting and modifying HTML elements.
* Events and event listeners.
* Form handling and validation.
* Rendering dynamic content.
* Browser storage with `localStorage`.
* Separating application logic from interface updates.

** Hands-On Output**

* Build a functional to-do application.
* Build an interactive quiz application.

### Week 8 — Asynchronous JavaScript & APIs

**Topics**

* Synchronous vs. asynchronous operations.
* Promises.
* `async` and `await`.
* Fetching data from APIs.
* JSON and data parsing.
* Error handling with `try...catch`.
* Closures and their practical uses.
* Classes and introductory object-oriented programming.
* Introduction to npm and package management.

** Hands-On Output**

* Build a weather application or movie-search application using a public API.
* Implement loading indicators and error messages.

###  MONTH 2 PROJECT — Interactive JavaScript Application

Build an interactive application that solves a simple problem or consumes data from an external API.

**Assessment:** Functionality, JavaScript fundamentals, code organisation, error handling, and the ability to explain your implementation.

**Topics**

* Git branches and pull requests.

##  MONTH 4 — Backend & Full-Stack Development

**Weeks 13–16 | Build the systems behind the interface.**

Learn how servers process requests, how databases store information, how authentication works, and how to connect frontend and backend applications into a complete system.

### Week 13 — Node.js, Express & REST APIs

**Topics**

* Introduction to Node.js.
* Server-side JavaScript.
* npm and backend project structure.
* Introduction to Express.js.
* HTTP methods and status codes.
* REST API principles.
* Routes and request handling.
* Middleware.
* Request parameters, query strings, and JSON bodies.
* Testing APIs with Postman.

** Hands-On Output**

* Build a REST API that supports basic CRUD operations using in-memory data.

### Week 14 — Databases & Data Persistence

**Topics**

* Introduction to databases and data modelling.
* MongoDB and Mongoose **or** PostgreSQL and SQL.
* Database connections and configuration.
* Creating, reading, updating, and deleting records.
* Data validation and relationships.
* Database queries.
* Persistent storage.
* Introduction to MongoDB Atlas if using MERN.

** Hands-On Output**

* Build a notes API or blog API connected to a real database.

### Week 15 — Authentication, Security & Full-Stack Integration

**Topics**

* User registration and login.
* Password hashing with bcrypt.
* JSON Web Tokens (JWT) and authentication concepts.
* Authentication vs. authorisation.
* Input validation.
* Environment variables and secret management.
* Cross-Origin Resource Sharing (CORS).
* Basic API security.
* Connecting React to the backend API.
* Handling authentication and API errors.

** Hands-On Output**

* Implement a registration and login flow.
* Connect the frontend to the backend.
* Demonstrate protected functionality.

### Week 16 — Capstone Sprint & Demo Day

**Topics**

* Full-stack application integration.
* Debugging and final testing.
* Deployment of frontend and backend.
* Production environment variables.
* Writing a professional README.
* Documenting APIs and setup instructions.
* Building a developer portfolio.
* CV and GitHub profile preparation.
* Mock technical interviews.
* Presenting projects and explaining technical decisions.

** Hands-On Output**

* Complete and deploy your full-stack capstone.
* Document your project.
* Present your application during demo day.
