
Syllabus
16 weeks, 4 months. Every month ends with a graded project. The stack is MERN (MongoDB, Express, React, Node).
Weekly rhythm
Day	Activity
Monday to Wednesday	Short concept session, live coding, guided lab
Thursday	Build day: work on the week's project in pairs
Friday	Demos, code review and a short checkpoint
Month 1 (Weeks 1-4): Computing foundations and the tech landscape
Week	Topics	Hands-on output
1	How computers work, the terminal, VS Code, Git and GitHub, learning from documentation	GitHub account, first repo, terminal scavenger hunt
2	Algorithms, flowcharts, variables, data types, conditions, loops, functions, debugging	10 small logic puzzles
3	How the internet works, HTML and CSS basics, databases (SQL vs NoSQL), APIs	Profile page on GitHub Pages
4	AI and machine learning, using AI tools responsibly, cloud computing, cybersecurity basics, software lifecycle, tech careers	One-page explainer and 5-minute group talk
Month 2 (Weeks 5-8): JavaScript
Week	Topics	Hands-on output
5	Syntax, types, operators, control flow, functions, scope, arrow functions	Daily coding drills
6	Arrays, objects, array methods, destructuring, spread, ES6 modules	Data-processing exercises
7	The DOM, events, forms, validation, localStorage	To-do app and quiz app
8	Promises, async/await, fetch, JSON, error handling, closures, classes, intro to npm	Weather or movie-search app
Month 3 (Weeks 9-12): Frontend development
Week	Topics	Hands-on output
9	Semantic HTML, accessibility, box model, Flexbox, Grid, responsive design, Tailwind CSS	Landing-page clone
10	Git branching and pull requests, React components, JSX, props, Vite	Component library of 5 components
11	State and hooks, forms, lists, conditional rendering, React Router	Multi-page React app
12	Data fetching, Context API, loading and error states, deployment, basic testing	Frontend capstone using a public API
Month 4 (Weeks 13-16): Backend and full-stack capstone
Week	Topics	Hands-on output
13	Node.js, Express, REST principles, routes, middleware, Postman	REST API with in-memory data
14	MongoDB and Mongoose, CRUD, relationships, Atlas	Notes or blog API on a real database
15	Authentication (bcrypt, JWT), validation, environment variables, CORS, security basics, connecting React to the API	Login and signup flow
16	Capstone sprint, deployment, README writing, portfolio and CV, mock interviews, demo day	Deployed full-stack capstone
Assessment
Projects, not exams. Each month ends with a graded project and a 30-minute code walkthrough. See the rubric.
Catch-up time
One Saturday per month is reserved for repeat sessions and one-on-one help.
